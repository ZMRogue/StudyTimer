# 📚 Study Timer

A beautiful web-based study timer to help you stay focused and productive!

## ✨ Features
- ⏱️ Customizable study and break timer
- 📊 Progress bar that fills as timer counts down
- 🔔 Sound alert when timer ends
- 🏆 Session counter to track completed sessions
- 🌙 Dark/Light mode toggle
- 💬 Random motivational quotes from API
- 🎵 Built-in music player with multiple genres
- 📖 Welcome intro screen

## 🎵 Music Options
- ☕ Lofi Hip Hop (Lofi Girl)
- 🎧 Chillhop
- 🌸 Spring Lofi
- 📚 Study Beats
- 🎼 Classical Sound
- 🎻 Beethoven
- 🎵 Best Classical

## 🚀 How to Use
1. Open `index.html` in any browser
2. Click **"Let's Start"** on the welcome screen
3. Set your study and break time
4. Click **START** to begin!
5. Pick your study music
6. Stay focused! 💪

## 🛠️ Built With
- HTML
- CSS
- JavaScript
- Quotes API (dummyjson.com)
- YouTube Embed API
